# Blackwell Studio

Design preview for an independent creative advertising studio. Nothing here is deployed.

- `preview/index.html` is the existing internal static reference. Leave it in place.
- `site/` is the React + Vite application. See [site/README.md](site/README.md) for install, build, preview, and the later GitHub Pages base path.
- [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) lists fonts and dependency licences.

```bash
cd site
npm install
npm run build
npm run preview
```
